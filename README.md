# Portfolio

Portfolio interactif 2D / 3D de Yoann : projets, compétences et contact.

**▶ Démo en ligne : [https://yoannservices.github.io/Y.Portfolio/](https://yoannservices.github.io/Y.Portfolio/)**

## Lancer en local

Aucune installation : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```

puis allez sur http://localhost:8000.

## Technologies

HTML, CSS et JavaScript, sans framework ni étape de build.
